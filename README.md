# Student API — Testing Guide (Postman / Thunder Client)

Base URL: `http://localhost:3000`

---

## GET

**Get all students**
```
GET http://localhost:3000/student
```

**Get a single student by ID**
```
GET http://localhost:3000/student/:id
```
Example:
```
GET http://localhost:3000/student/1
```

---

## POST

**Add a new student**
```
POST http://localhost:3000/student
```

Body (raw JSON):
```json
{
  "name": "John Doe",
  "age": 20,
  "course": "BSIT"
}
```

> Note: `id` is auto-generated by the server and does not need to be included in the request body.

---

## PATCH

**Update an existing student by ID**
```
PATCH http://localhost:3000/student/:id
```
Replace `:id` with the actual student ID.

Example:
```
PATCH http://localhost:3000/student/1
```

Body (raw JSON) — include only the fields you want to update:
```json
{
  "age": 25
}
```

---

## DELETE

**Remove a student by ID**
```
DELETE http://localhost:3000/student/:id
```
Replace `:id` with the actual student ID.

Example:
```
DELETE http://localhost:3000/student/1
```

---

## Notes
- For POST and PATCH requests, set the request body type to **raw → JSON** in Postman/Thunder Client.
- Make sure the `Content-Type: application/json` header is set.
